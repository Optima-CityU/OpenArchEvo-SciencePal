# r02a-e29092 — design rationale (written by the proposing agent)

The parent i00-deltanet is a hybrid spiking-recurrent architecture where all major projections are spiking, but the output projection o_proj is a standard SpikingLinear that directly maps the attention output to the model dimension. I introduce a spiking gate after the o_proj, which multiplies the output by a binary spike vector generated by an additional SpikingLinear. This gate acts as a learned binary mask that can zero out portions of the output, increasing sparsity and reducing the effective firing rate of the block. The gate is applied after the output projection but before the residual connection, so it can selectively suppress information flow. This is a single coherent mechanism change that should increase sparsity while preserving the core DeltaNet recurrent computation.
