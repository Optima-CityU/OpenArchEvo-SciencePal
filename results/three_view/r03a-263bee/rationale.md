# r03a-263bee — design rationale (written by the proposing agent)

The parent i00-deltanet is a hybrid SNN model where the core DeltaNet projections are spiked. To explore a new mechanism, I introduce a spiking gate in the output projection path. A new SpikingLinear layer (g_proj) projects the input to d_model, and its output is passed through a sigmoid to create a gate. The output of the o_proj is then multiplied by this gate. This gating mechanism is inspired by gated linear attention, but here it uses a spiking linear layer to produce the gate signal. This is expected to reduce the firing rate because the gate can suppress outputs, leading to more zeros in the final output spikes. The parameter increase is small (d_model^2), which is within the 5% tolerance for a 34128-parameter block.
