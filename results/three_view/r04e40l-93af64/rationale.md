# r04e40l-93af64 — design rationale (written by the proposing agent)

The directive asks to recombine r03e40l-1fc3a4 (DeltaNet, shared qk_proj, no b_proj, expand_k=0.75) with r02e40l-31b232's per-head SiLU gating (g_proj), but apply the gate only to the value path before the delta-rule write, not before o_proj. 31b232's full gating (before o_proj) regressed to 85.6. This child adds a g_proj (SpikingLinear, d_model -> value_dim) to 1fc3a4, computes a per-head gate g = SiLU(g_proj(x)), reshapes it to (B, H, L, D_v), and multiplies it with the value v before the delta-rule call. This means v is gated before it is used in both the intra-chunk attention and the state update, modifying a live computation path: the value tensor v that feeds directly into the delta-rule write. The shared-qk, no-b_proj core of 1fc3a4 is preserved. The gate is applied per-head (via head_v_dim) and is multiplicative (SiLU, can both attenuate and amplify), so it is not an attenuate-only sigmoid. This should give the quality benefit of gating without the regression observed from gating after the recurrence.
