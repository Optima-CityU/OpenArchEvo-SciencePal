Lab session (OpenArchEvo GPU jobs). Work unattended; never ask questions; no web search. Keep messages short (one line per check) to save tokens.

Important facts: packages installed into the system Python are reset between sessions; only /workspace persists. The controller therefore keeps a private virtual environment at /workspace/venv. Always use /workspace/venv/bin/python for this work. Do not pip install into the system Python and do not modify /workspace/lab/lab_setup.sh or lab_worker.py.

1. Run `bash /workspace/lab/lab_setup.sh > /workspace/lab/setup.out 2>&1` (first run downloads ~3 GB and may take 10-15 minutes; later runs take seconds). Run it in the background and poll every 2 minutes until the line SETUP_DONE appears in /workspace/lab/setup.log. Then print the last 12 lines of /workspace/lab/setup.log. If torch is not CUDA-enabled or fla is missing after setup, print the relevant part of setup.log, try once to fix it inside /workspace/venv only, and continue.
2. Start the queue worker detached with the venv interpreter:
   cd /workspace/lab, delete a file named STOP if present, then start `/workspace/venv/bin/python lab_worker.py` with nohup, environment variable LAB_MAX_PARALLEL=2, stdout/stderr to worker.log, in the background, and save its PID to worker.pid.
3. Supervise. Every 4 to 5 minutes (sleep 240 between checks) print one line with the content of /workspace/lab/heartbeat.json and the number of files in /workspace/lab/results. Also print `free -m | head -2` once after the first jobs start. The controller adds new job files to /workspace/lab/queue/ while you supervise; that is expected. If the worker process dies, print the tail of worker.log, restart it once the same way, and note it.
   Stop supervising when ANY of these holds: (a) the file /workspace/lab/SESSION_END exists; (b) the queue is empty, nothing is running and no new result appeared for 25 minutes; (c) 170 minutes have passed since step 2.
4. Write /workspace/lab/supervise_report.json with: setup outcome (torch/fla versions, cuda), worker start time, end time, stop reason, number of results, restarts, and the last 20 lines of any failed job log in /workspace/lab/logs. Do not stop the worker yourself. Print the report path as the last line.
