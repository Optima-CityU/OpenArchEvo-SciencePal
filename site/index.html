Why change the scoring rule?

Searches rank hundreds of candidates with 2-epoch training, but the 2-epoch score barely predicts the 30-epoch result (Spearman −0.01 on 29 new architectures). Analysing the training logs, we derived an overfitting-aware score, OAF = val₂ + 0.5·(val₂ − train₂) (coefficient chosen on 18 architectures, then frozen), with rank correlation 0.64 on new architectures (2-epoch score: −0.01). Five SciencePal models, not told about OAF, proposed several scoring formulas from the same logs; the best one (GPT-6.1) performed on par with OAF. OAF is not infallible: in one quick-score-only run it also picked a design that stalled.

Method

What the agents add around OpenArchEvo

Grey: the OpenArchEvo engine, unchanged. Blue: what agents add. Terracotta: the tests that decide what stays.

The grey loop is simply: propose → check → train → keep the best. The blue agents make each step smarter; the terracotta tests decide which changes stay.

A controller outside the platform calls the agents in order; all sessions, GPU training and the Skill live on SciencePal.

What SciencePal provides

More than one coding agent: its own GPU labs, several model families and a shared, improving playbook, all in one place.

What the search found

A gate that listens to spikes

Task: predict the next word. Spiking networks pass only 0/1 signals, saving energy. This gate reads the spikes directly, no sigmoid: 68.95 vs 71.8 (expert) and ≈70.7 (same-size controls).

Explore the tested configurations

WikiText-2 validation PPL, 30 epochs, mean over seeds; every configuration was trained
Why it matters

The common sigmoid gate is worse in this position, and without spikes on its input most of the gain disappears. It is a design native to spiking networks, found by searching over code.

Invisible to the quick test
117.70 · 117.662-epoch score (champion · sigmoid twin)
68.95 · 73.5430 epochs
Details: controls, test set and longer context

Champion over 3 seeds (68.88–69.02). Same-size controls: wider DeltaNet 70.74, DeltaNet's built-in gate 70.66. Test PPL: 61.65 vs 63.80 for DeltaNet.

At 4× context (sequence length 512, 15 epochs, 2 seeds): champion 74.30, DeltaNet 74.66, same-size control 75.19; all three are within seed noise (the control's seeds differ by 1.8), so transfer is not shown. The mechanism is still unknown: the hypotheses we pre-registered were all refuted.

Origin: the champion came from an agent-driven search during the hackathon (Skill v0.3.3), and it was the 2-epoch best of its own run, but that score (117.70) could not be told apart from losers such as its sigmoid twin (117.66). Only 30-epoch training showed it was the winner. That is where our work on the scoring rule began.

Improving the method

Agents rewrite their own Skill; a benchmark keeps only improvements
