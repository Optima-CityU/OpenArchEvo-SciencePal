- **H1**（≥ 3 个模型提出过拟合 / 容量类）：**成立**（5/5）。

## 解读
- **"容量"不是主因：** 只缩容量的 i2 没用，甚至更差。改门的取值范围（i1）或位置（i4）才有效。
  - 过拟合的直接原因更像是：门在 (0, 1) 区间对输出做逐通道衰减，并且放在投影之后。
  - 5 个模型中 4 个最先提出"容量"，GPU 实验否定了这个最流行的假设。这正是"众智提出、实验裁决"的价值。
- **i4 与专家设计殊途同归：** 把门放到输出投影之前（70.72），几乎就是 DeltaNet 自带、默认关闭的 `use_gate` 设计（70.44 / 70.66）。
  - Agent 从失败曲线出发，独立地走回了专家设计。演化搜索的 2 轮适应度没有选中它，30 轮确认才显示它的价值。
- **模型预测的校准：**
  - DeepSeek‑Pro 两个假设的方向都对；
  - GPT 对同一干预的数值预测偏悲观；
  - "最流行的假设"不等于"对的假设"。
