# 第八轮实验总结（10/29 14:00 – 10/30 12:00，约 22 h，15 个 GPU 实验室）

所有新实验先写预注册（`PREREG_night4.md` 第八轮各节，带时间），再收结果；事后发现单独标注。数字均为协议 `sp-wt2-sltt-s128-*`（SLTT 神经元，seq 128），不与论文 SDN 协议混用。GPU：本轮约 90 个 30 轮训练、约 40 个 6 轮、约 150 个 2 轮。

## 一句话

## 5. 闭环演示与门机制
- **E27：** Skill v0.5.1（6 张来自 GPU 实验的经验卡）不退化，晋级（首次通过 70% vs 75%，distinct_new 40 vs 37）。
- **E34（一代完整闭环）：** v0.5.1 以冠军为父代提出 12 个，过 CPU 门，训 2 轮，按 OAF 选 2 个训 30 轮，得到 68.90 和 69.34，与冠军持平。
- **E33 / E35 / E36 / E37（`o_proj` 后门的激活）：**
  - identity 68.95、soft‑clip 69.20（GPT‑6.1 提出，3 种子）、abs 69.70、tanh 70.16、1 + g 70.54；
  - SiLU 71.75（4/5 模型一致提出）、1 + tanh 71.96、sigmoid − 0.5 72.88、sigmoid 73.54、2·sigmoid 74.14。
  - 事先写下的三个机制假设（符号、可放大、静息为 0）**全部被否定**；面板多数派的 SiLU 也被否定。确认的只有"在这个位置去掉 sigmoid"。机制如实列为开放问题。

## 7. 独立核对（另一个 Agent 从原始数据重算）
- 1–4 节的核心数字全部一致（E31 样本外 ρ(OAF) = 0.633，bootstrap 95% [0.32, 0.82]；E30 ρ = 0.005）。这 28 个架构与选 λ 用的 18 个不重叠。
- 需要在终稿注明的说明：
  1. **r08a‑fb7725 与 r03a‑263bee 功能完全相同**（代码只差统计记录，PPL 逐位相同）。E29 按 ID 去重，没有排除它。去掉或换掉后：样本外 ρ(OAF) 0.627；2 轮组均值 73.90。结论不变。
  2. E31 的 28 个里有 7 个用的是 2 轮重跑（搜索期日志在已停用的实验室上，取不到）。只用搜索期日志的 21 个：ρ(val₂) 0.06，ρ(OAF) 0.79。**正文报 n = 28、0.63**，不报中期的 0.86。
  3. DeltaNet 的 30 轮里种子 0 有两次逐位相同，独立值 5 个：均值 71.84，按种子先平均 71.82。统一写 71.8。
  4. E30 各组每次运行的预算不完全相同（A5 / V2nk 每次 17 个训练，e7 每次 26–33 个），组间比较只作描述。
  5. **OAF 的解释要谨慎：** OAF = 1.5·val₂ − 0.5·train₂；第 2 轮 train₂ 远大于 val₂（训练 PPL 是带 dropout 的整轮平均），单用 −train₂ 在样本外就有 ρ = 0.50。"过拟合缺口"是一种解释，未经机制验证。λ 在 0.25–2 之间时 ρ 为 0.42–0.65。
- 没有发现协议混用（全部用验证集 wikitext2_ppl）。
- E25 补充（10/30 11:45）：i1 三种子 71.76 / 71.49 / 71.60，均值 71.62（略好于 DeltaNet 71.8，差距 < 0.5）。所有 GPU 任务已完成，实验室守护已停（10/30 11:46）；worker 与 feeder 仍在，需要时可直接加任务。
